Automatización de consultas de inventario con IA

Asistente que interpreta consultas en lenguaje natural y obtiene información desde inventario y precios reales.

Problema
Las consultas de repuestos contienen errores, expresiones informales, sinónimos y datos incompletos que dificultan identificar una pieza con precisión.

Solución
Arquitectura modular en Python integrada con OpenAI API y Airtable. Extrae repuesto, marca, modelo y año; normaliza términos, conserva contexto y solicita aclaraciones cuando la información es insuficiente.

Resultado
Consulta inventario y precios sin inventar disponibilidad, valores ni compatibilidades. La lógica contempla ambigüedades, tolerancia a errores y validación mediante una batería de 49 casos de aceptación.

✓ Lenguaje natural y extracción de entidades✓ Memoria contextual✓ Integración con datos reales✓ Controles contra respuestas sin respaldo

02
◇

TrendWave

Automatización inteligente para analizar, clasificar y gestionar postulaciones.

Problema
Revisar postulaciones manualmente exige extraer información, normalizar datos, comprobar criterios y comunicar el resultado a cada persona.

Solución
Flujo en Make que recibe textos mediante webhook, utiliza Gemini para extraer cinco campos en formato JSON y aplica reglas de aprobación según los datos obtenidos.

Resultado
Router dirige cada resultado, Google Sheets mantiene el registro y Gmail envía comunicaciones diferenciadas. El proceso fue modelado en Bizagi para documentar decisiones, rutas y responsabilidades.

✓ Recepción mediante webhook✓ Extracción estructurada con Gemini✓ Clasificación y enrutamiento automático✓ Registro y notificaciones

Stargaze

Plataforma Full Stack para publicación y gestión de eventos.

Problema
Centralizar publicaciones de eventos permitiendo que cada usuario administre su contenido e interactúe con otras publicaciones.
